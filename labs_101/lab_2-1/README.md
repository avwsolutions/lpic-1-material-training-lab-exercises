## Over dit lab

Dezelfde taken uitvoeren in de Red Hat- en de Debian-familie: package bij een bestand zoeken, installeren uit repositories, informatie en dependencies opvragen, integriteit controleren en weer verwijderen.

## Voorbereiding

Je hebt sudo-rechten nodig op beide VM’s en een werkende internetverbinding voor de repositories.

## Opdrachten

1. CentOS: uit welk package komt `/usr/bin/ssh`, en welke bestanden levert dat package nog meer?
2. Ubuntu: beantwoord dezelfde twee vragen voor `/bin/ls`.
3. Zoek op beide systemen in de repositories naar `nmap` en installeer het package.
4. Toon de versie-informatie van `nmap` en de lijst met dependencies.
5. Controleer op CentOS de integriteit van het geïnstalleerde package.
6. Verwijder `nmap` weer; op Ubuntu inclusief configuratiebestanden.
7. Zoek op beide systemen op welke repositories zijn geconfigureerd.
